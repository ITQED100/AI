# AI Playground

This directory is my personal playground for exploring, building, and testing AI projects.

The goal is to use this space for hands-on learning across areas such as:

- Generative AI
- Retrieval-Augmented Generation (RAG)
- Agentic workflows
- Tool calling
- AI search and vector retrieval
- Prompt design
- Requirements engineering
- AI application architecture
- Model evaluation and validation

Each project in this folder is intended to be a practical learning exercise rather than a production system.
